Starting from MAI-Base-1, three specialist models are trained independently via RL (STEM, Agentic, Helpfulness & Safety). These are then consolidated into a single model via SFT distillation, followed by a final lightweight RL stage to produce MAI-Thinking-1.

What happens in the RL Climb?

Pre-training gives the model knowledge and language ability, but it doesn't teach the model how to reason step-by-step, use tools, or follow safety guidelines. The RL climb addresses this by optimizing the model against task-specific feedback.

The key insight: instead of trying to train one model to do everything at once, the team trained three specialist models in parallel, each focused on a different skill set:

  • STEM specialist — math, science, and competitive programming
  • Agentic specialist — software engineering and tool use
  • Helpfulness & Safety specialist — following instructions, being honest, staying safe

These specialists were then merged into a single model using self-distillationA technique where a model learns from its own previous outputs. The team collects good reasoning traces generated during RL, then trains a fresh model on those traces via supervised learning. This effectively "carries forward" discovered capabilities to a new starting point.Learn more and a final lightweight RL stage.
