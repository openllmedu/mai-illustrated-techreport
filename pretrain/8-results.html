Section 2.7

Results vs. Other Models

How MAI-Base-1 compares to DeepSeek, Gemma, and Kimi base models

TL;DR

MAI-Base-1 achieves lower BPB (bits-per-byte, a tokenizer-agnostic quality metric) than models with comparable active parameters across all held-out evaluation tasks. DeepSeek-v4 achieves the best overall BPB but uses 1.4x more active and 1.6x more total parameters. A prior MAI 23B model outperforms DeepSeek v3.2 at only 62% of its active parameter count.

The team compared MAI-Base-1 against open-weight frontier base models using bits-per-byte (BPB)A tokenizer-agnostic metric for comparing language models. Lower BPB = the model compresses text better = better language understanding. Unlike NLL, BPB normalizes across different tokenizers, enabling fair comparison.Learn more — a tokenizer-agnostic metric that enables fair comparison across models with different vocabularies.

What does BPB actually mean? Feed a 10,000-character physics textbook to two models. Model A assigns BPB = 0.50, meaning it needs 0.50 × 8 = 4.0 bits per byte to encode the text — it compressed the textbook to 50% of its raw size because it predicted the content well. Model B scores 0.45 BPB (3.6 bits/byte) — it compressed to 45%, meaning it predicted the physics text more accurately. Lower BPB = better understanding. By normalizing to bytes instead of tokens, BPB enables fair comparison even when models use completely different tokenizers.

Models compared: DeepSeek v3.2, DeepSeek v4 Pro, Kimi-K2, Gemma4-31B, plus a prior MAI 23B model.

Key Comparisons

MAI-Base-1 vs. Similar-Size Models

Clear advantage over models with comparable active parameter counts across all four evaluation tasks (vendor-created STEM, math, code, and general knowledge evaluations).

MAI-Base-1 vs. DeepSeek-v4

DeepSeek-v4 achieves the best BPB overall, but with 1.4x more active parameters (~50B vs. 35B) and 1.6x more total parameters (~1.6T vs. 1T). Per-parameter, MAI-Base-1 is more efficient.

MAI 23B vs. DeepSeek v3.2

The prior-generation MAI 23B model (also trained for 30T tokens) outperforms DeepSeek v3.2 while using only 62% of its active parameters — demonstrating the accumulated gains from the architecture and data improvements.

Important Caveats

  • These are base model comparisons (before any post-trainingAll training that happens after pre-training: Supervised Fine-Tuning (SFT), Reinforcement Learning from Human Feedback (RLHF), and other alignment techniques. Post-training shapes the model's behavior, safety, and instruction-following ability.Learn more/RL/RLHFReinforcement Learning from Human Feedback — a technique where the model learns from human preferences. Humans rank model outputs, a reward model is trained on these rankings, and the LLM is optimized to maximize the reward. Key to making models helpful, harmless, and honest.Learn more). The real-world performance of final products also depends on the post-training recipe.
  • NLL/BPB evaluation is not possible through most model APIs, so only open-weightModels whose trained parameters (weights) are publicly released for download, typically on HuggingFace. This allows researchers to run the model locally, inspect its internals, and evaluate with NLL/BPB — unlike API-only models where you can only send queries.Learn more models hosted on HuggingFace could be compared.
  • Evaluations use internal held-out data — one based on the team's own training stack source code, others vendor-commissioned — ensuring decontamination from all models' training data.
MAI-Base-1 demonstrates state-of-the-art pre-training efficiency for its parameter class. The systematic approach — scaling ladders, rigorous ablations, careful data curation, and hardware co-optimization — produces a strong foundation for the reinforcement learning climb that follows in Chapter 3.
