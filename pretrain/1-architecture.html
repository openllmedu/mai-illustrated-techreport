Section 2.1

Model Architecture

The structural blueprint of MAI-Base-1 — a sparse MoE Transformer co-designed with GB200 hardware

TL;DR

MAI-Base-1 uses a decoder-only Transformer with 78 layers, alternating dense FFN and 512-expert MoE layers (top-8 routing), periodic local/global attention (5:1 ratio), and LatentMoE compression for efficient cross-GPU communication. Every architectural choice was co-optimized with the underlying GB200 GPU infrastructure.

MAI-Base-1 is a decoder-only TransformerThe dominant architecture for modern language models. It generates text left-to-right, predicting one token at a time based on all preceding tokens.Learn more with 35B active / ~1T total parameters. Its architecture was co-designed with the GPU hardware to maximize both model quality and training efficiency.

Why Decoder-Only?

There are three main Transformer architectures: encoder-only (BERT — reads all tokens bidirectionally, used for classification/retrieval), encoder-decoder (T5 — reads input bidirectionally, generates output left-to-right, used for translation), and decoder-only (GPT, Claude, LLaMA, MAI — generates text left-to-right, each token can only attend to preceding tokens).

Decoder-only dominates modern LLMs because it uses a single architecture for both understanding and generation. The causal mask ensures each token only sees previous tokens, enabling autoregressive generation: the model produces one token at a time, feeding each output back as input for the next step. This makes it naturally suited for chat, code generation, and reasoning — the model builds its answer incrementally.

In a causal/decoder model processing "The cat sat on," the token "on" can attend to "The," "cat," "sat," and itself — but never to future tokens. When generating the next word, the model runs "on" through all 78 layers, each time attending only to cached key-value pairs from previous tokens. This is why the KV cache (storing past keys and values) is so critical for inference speed — without it, every new token would recompute attention over the entire sequence from scratch.

Three Key Design Choices

1. Periodic Local + Global Attention

We pair 5 local attention layers with 1 global attention layer, which significantly reduces the computational cost of attention for training and KV cache size during inference.

AttentionThe mechanism that lets each token "look at" other tokens to understand context. Global = looks at everything; local = only nearby tokens within a sliding window.Learn more is the most expensive operation in a Transformer. 5 out of every 6 layers only look at a small window of 512 nearby tokens (local attention). Only every 6th layer uses global attention. The local layers use RoPERotary Position Encoding — a way to encode token positions so the model knows word order. Used in local attention with base frequency 10,000.Learn more for position encoding; global layers use no position encoding at all (found to perform comparably while being more efficient).

Consider a 16,384-token input (about 12 pages of code). In a local attention layer, token #8,000 can only see tokens #7,744–#8,256 — a sliding window of 512. It cannot see a function defined at token #200 or a variable used at token #15,000. Every 6th layer is global: token #8,000 attends to all 16,384 tokens, connecting a function call with its definition 8,000 tokens away. With 78 layers total, there are 13 global layers providing these long-range connections, while the other 65 local layers handle nearby context at much lower cost.

2. Interleaved Dense FFN + High-Sparsity MoE

We alternate between MoE layers and dense FFNs. This paradigm scales comparably to medium-sparsity MoEs throughout while being more efficient in wall-clock time.

Instead of making every feed-forward network (FFN)The part of each Transformer layer that processes each token independently. It applies a non-linear transformation using SwiGLU activation.Learn more a sparse MoE (the common approach), MAI-Base-1 alternates: one layer has a massive 512-expert MoE (top-8 routing), the next has a small dense FFN (always fully active). This matches quality while training faster.

Notably, this interleaved layout relies much less on shared expertsExperts that are always activated for every token, in addition to the top-k routed experts. Common in DeepSeek-style architectures. MAI found them unnecessary with interleaved design.Learn more — adding them provides little or no benefit, unlike in every-layer-MoE architectures.

3. LatentMoE (Compressed Expert Routing)

A shared down-projection is applied before the all-to-all dispatch. Routing decisions are based on the original representation, and each compressed representation is routed to 8 out of 512 experts.

Before sending tokens to experts across GPUs (expensive all-to-all communicationA collective operation where every GPU exchanges data with every other GPU. Necessary for MoE routing when experts live on different GPUs.Learn more), tokens are compressed to half size via a shared down-projection. Experts work on compressed representations, then expand back. Routing decisions use the full-sized representation for better accuracy.

Concrete numbers: each token arrives as a 6,656-dimensional vector. The router examines this full vector to pick the best 8 experts. Then a shared projection shrinks it to 3,328 dimensions before sending it across the network to those experts — halving the data transferred between GPUs. Each expert expands 3,328 → 9,984 (3x), applies SwiGLU, projects back to 3,328. After combining the 8 experts' outputs, a shared up-projection restores it to 6,656 dimensions.

Attention Variants: MHA vs GQA vs MQA

Standard Multi-Head Attention (MHA) gives each query head its own key-value head — 80 Q heads x 80 KV heads. Every Q head gets an independent attention pattern, but the KV cache stores 80 separate K and V vectors per token per layer. Multi-Query Attention (MQA) goes to the other extreme: all query heads share a single KV head — maximum cache compression but reduced quality. Grouped-Query Attention (GQA) splits query heads into groups that share a KV head — the practical middle ground.

Key relationship: Q heads x d_head = d_model always (80 x 128 = 10,240 for MAI-Base-1). In GQA, each KV head is shared by a group of Q heads (80 / 8 = groups of 10), reducing KV cache by 10x with minimal quality loss.

Positional Encoding: How Tokens Know Their Order

Attention is permutation-invariant — without position information, "dog bites man" and "man bites dog" look identical. MAI-Base-1 uses RoPE (Rotary Position Embedding) for local attention layers and no position encoding for global layers.

RoPE works by rotating pairs of dimensions in the Q and K vectors based on position. For dimension pair (d0, d1): q'_d0 = q_d0 x cos(theta) - q_d1 x sin(theta), where theta depends on the token's position. When Q at position 5 dot-products with K at position 3, the rotation angles partially cancel — the attention score depends only on the relative distance (5-3=2), not the absolute positions. Different dimension pairs rotate at different frequencies: low dimensions rotate fast (fine position detail), high dimensions rotate slowly (coarse position).

MAI-Base-1's global attention layers use no position encoding at all — an unusual choice validated by ablation. Global layers fire only every 6th layer, and the team found they perform comparably without position info while being more efficient. This saves compute and simplifies long-context extension. The local layers handle positional relationships within their 512-token window, and global layers aggregate information position-agnostically.

Normalization and Residual Connections

MAI-Base-1 applies RMSNorm at both input and output of each layer, immediately before the residual addition. This follows the Gemma 3 "pre-norm + post-norm" pattern. RMSNorm is simpler and ~10-15% faster than standard LayerNorm — it only normalizes the scale (root mean square), not the mean.

Residual (skip) connections are the mechanism that makes 78-layer models trainable. Each layer computes: output = input + Layer(Norm(input)). The "input +" term provides a direct gradient highway — even if a layer's gradient is near zero, the skip connection preserves the signal. Without residuals, a 78-layer model's gradients would shrink by ~0.9^78 = 0.0004 before reaching the first layer — effectively zero, making early layers unlearnable.

The architecture prioritizes hardware efficiency alongside model quality. Every choice — local attention ratio, interleaved MoE, latent compression, GQA — was validated at multiple scales through the ablation methodology described in the next section.
